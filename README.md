# Repositorio de Tareast
# Challenge 13 - GIF Search


## Funcionalidades

- Búsqueda de GIFs mediante un campo de texto.
- Visualización de hasta 25 GIFs por búsqueda.
- Consumo de la API mediante Fetch.
- Manejo de errores y estados de carga.
- Diseño adaptable a diferentes pantallas.

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- CSS
- Fetch API
- GIPHY API

## Instalación

1. Clonar el repositorio.
2. Instalar las dependencias con `npm install`.
3. Crear un archivo `.env` en la raíz del proyecto.
4. Configurar la variable `VITE_GIPHY_API_KEY` con una clave de GIPHY.
5. Ejecutar `npm run dev`.
